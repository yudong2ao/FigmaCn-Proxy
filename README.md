# Figma 汉化代理与启动脚本

本项目基于 [Mitmproxy](https://mitmproxy.org/) 实现。主要功能为：通过本地代理拦截 Figma 客户端的语言包请求并重定向至第三方中文语言包，配合透明代理工具（如 ProxyBridge / Proxifier）实现对 Figma 的完美、零延迟汉化。

## 🚀 核心架构：网络层降维打击

经过多轮迭代，本项目彻底抛弃了“劫持并修改系统快捷方式参数”的传统做法，改用**透明代理/进程代理**方案。
无论你是通过快捷方式启动、双击 `.fig` 文件启动，还是在软件内部点击“立即更新重启”，Figma 的流量都会在网络底层被无缝劫持。这彻底根除了 Figma 更新后参数丢失、汉化失效的顽疾。

同时，新增的启动脚本 `FigmaCn.vbs` 会在每次启动时自动巡检并清理旧版本产生的垃圾文件（如 `app-xxx` 文件夹），有效节省 C 盘空间。

## 📦 快速食用指南

你可以选择直接下载打包好的**“懒人包”**（内含预先准备好的 `mitmdump.exe`，无需配置环境），或者**自行准备环境**：前往 [Mitmproxy 官网](https://mitmproxy.org/) 下载对应系统的安装包，提取其中的 `mitmdump.exe` 放入本项目的根目录下。

只要确保根目录下有 `mitmdump.exe`，就可以按照以下步骤开箱即用：

### 第一步：初次使用，生成并安装根证书 (仅需一次)
为了拦截 HTTPS 请求，你需要生成信任证书并将其安装到系统中：
1. 双击运行目录下的 `mitmdump.exe`，等待命令行出现并生成相关文件后，按 `Ctrl+C` 退出。
2. 进入 `C:\Users\你的用户名\.mitmproxy\` 文件夹，找到并双击 `mitmproxy-ca-cert.p12` 文件开始安装。
3. **【关键】** 在弹出的导入向导中，存储位置请选择 **“当前用户 (Current User)”**，点击“下一步”。（注：选择当前用户最安全且不需管理员权限，足以满足 Figma 汉化需求）。
4. 出现密码设置提示时，无需设置任何密码，直接点击“下一步”。
5. **【最关键】** 选择证书的存储区域：
   - 选择 **“将所有的证书都放入下列存储”**。
   - 点击“浏览”按钮，在弹出的窗口中严格选择 **“受信任的根证书颁发机构”**，点击“确定”。
   - 点击“下一步”。
6. 点击“完成”结束导入。如果期间有安全警告弹出（询问是否信任该证书），直接点击“是”即可完成安装。

### 第二步：配置进程代理 (以 ProxyBridge / Proxifier 等工具为例)
在你的代理工具中，添加一条专门针对 Figma 进程的规则：
- **目标进程**: `Figma.exe`
- **动作 (Action)**: 强制转发给 HTTP 代理 `127.0.0.1:8089`。

### 第三步：运行启动器 `FigmaCn.vbs`
- 双击运行根目录下的 `FigmaCn.vbs`。
- **它的作用极简且纯粹**：
  1. 在后台静默拉起 `mitmdump`（监听在 `8089` 端口，并挂载汉化拦截脚本 `figma_zh_cn.py`）。
  2. 自动清理多余的 Figma 更新垃圾。
  3. 脚本执行完毕后**立即退出，实现 0 内存驻留**。

### 💡 进阶使用：开机自启与关闭代理
- **开机自启 (推荐)**：建议为 `FigmaCn.vbs` 创建一个快捷方式，并将其放入 Windows 的“启动”文件夹（`Win+R` 输入 `shell:startup`）。这样每次开机都会自动在后台备好翻译服务并顺手清理垃圾。
- **手动关闭服务**：打开 Windows 任务管理器，结束 `mitmdump.exe` 进程，或者在命令提示符中执行：`taskkill /f /im mitmdump.exe`。
