# Figma 客户端汉化脚本与代理自启配置

本项目基于 [Mitmproxy](https://mitmproxy.org/) 实现。主要包含两个部分的功能：一方面通过本地代理实现 Figma 客户端的中文汉化，另一方面实现了 Mitmproxy 的后台静默运行与开机自启。

---

## 第一部分：使用 Mitmproxy 实现 Figma 汉化

### 1. 原理说明
Figma 客户端在启动时会请求官方的英文语言包。本脚本通过本地代理拦截该请求，并返回 HTTP 307 重定向，将其指向第三方开源的 [Figma 中文语言包](https://kailous.github.io/figma-zh-CN-localized/lang/zh.json)。核心拦截逻辑位于 `figma_zh_cn.py`。

### 2. 运行环境与依赖
1. **Python**: 确保你的电脑上已安装 Python 3。
2. **Mitmproxy**: 使用 pip 安装 mitmproxy：
   ```bash
   pip install mitmproxy
   ```

### 3. 安装根证书
由于我们需要拦截并修改 HTTPS 请求，必须安装 Mitmproxy 的根证书。
1. 双击目录下的 `mitmproxy-ca-cert.p12` 文件。
2. 证书存储位置选择 **本地计算机**（或当前用户）。
3. 选择 **将所有的证书都放入下列存储**，点击“浏览”。
4. 选择 **受信任的根证书颁发机构**，然后一直点击下一步直至完成安装。

### 4. 配置 Figma 客户端代理（推荐方式）
为了不影响系统的全局网络请求，建议直接通过快捷方式为 Figma 客户端单独设置代理参数，而不是使用系统全局代理。

**配置说明**：
- **不要修改官方默认快捷方式**：Figma 官方默认生成的快捷方式，其指向的目标路径通常带有具体版本号（例如 `app-xxx\Figma.exe`）。当 Figma 自动更新后，旧版本路径失效，官方快捷方式会被重置，从而导致你添加的代理参数丢失。
- **正确的配置位置**：请找到 Figma 安装根目录下的主程序（通常默认安装在 `C:\Users\你的用户名\AppData\Local\Figma\Figma.exe`）。
- **最佳实践**：
  1. 找到根目录下的 `Figma.exe`，右键选择“发送到” -> “桌面快捷方式”。
  2. 在桌面上找到新创建的快捷方式，右键点击选择“属性”。
  3. 在“目标”一栏的末尾，先输入一个空格，然后加上代理参数：
     `--proxy-server=127.0.0.1:8089`
  4. 点击“确定”保存。
  5. 建议将此自定义快捷方式放入“开始菜单”，替换掉官方的原有快捷方式。以后每次通过此快捷方式启动 Figma，即可稳定生效汉化效果，且不受客户端更新影响。

## 第二部分：实现 Mitmproxy 静默及开机自启

### 1. 脚本说明
- `run_mitmdump.py`: Python 包装脚本，用于配置并启动 `mitmdump`（默认监听 `8089` 端口，并加载汉化脚本）。同时处理了标准输入输出以防止后台运行崩溃，日志会统一输出到 `mitm_startup.log`。
- `MitmServer.vbs`: VBScript 脚本，通过 `WScript.Shell` 在后台静默启动 `python.exe` 进程并运行上述 Python 脚本，避免运行期间出现命令提示符的黑框。

### 2. 测试静默运行
- 直接双击目录下的 `MitmServer.vbs`，即可在后台静默启动代理服务。
- 若需要查看运行状态或排查报错，可以打开同目录下生成的 `mitm_startup.log` 文件确认。

### 3. 配置开机自启
要实现每次电脑开机时自动在后台静默运行代理服务，请按以下步骤操作：
1. 右键点击 `MitmServer.vbs` 文件，选择“创建快捷方式”。
2. 按下 `Win + R` 键打开运行窗口，输入 `shell:startup` 后回车，会打开 Windows 系统的“启动”文件夹。
3. 将刚才创建的快捷方式剪切并粘贴到这个“启动”文件夹中。
4. 下次重启电脑后，Mitmproxy 就会在后台静默启动了。

### 4. 关闭代理服务
因为脚本是在后台静默运行的，若想停止服务，可通过以下方式：
- 打开 Windows 任务管理器（按 `Ctrl + Shift + Esc`）。
- 找到 `python.exe` 进程（可根据内存占用，或右键列加入命令行参数选项以辨别），选中并点击“结束任务”。
- 或者在命令提示符 (CMD) 中执行以下命令强行关闭：`taskkill /f /im python.exe`（**注意**：此命令会关闭所有正在运行的 Python 进程）。
